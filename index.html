本機與 Google 雲端存檔

本機自動存檔已啟用。Google 功能需先設定 Firebase。

本機會自動存檔；雲端採手動「儲存／讀取」， 避免登入時覆蓋另一台裝置的進度。可先匯出 JSON 備份。 單人遊戲存檔，不含線上對戰或防作弊。

第一次啟用 Google：設定步驟
  1. 到 Firebase Console 建立自己的專案、新增 Web App，複製 firebaseConfig 物件。
  2. Authentication 開啟 Google 登入，設定支援信箱，並在授權網域加入遊戲網域，例如你的 GitHub Pages 網域。
  3. 建立 Cloud Firestore（預設資料庫），將以下規則發布到 Rules。
  4. 將 Web 設定以 JSON 格式貼到下方，按「套用設定」。只貼 Web 設定，不要貼服務帳號私鑰。
  5. 透過 HTTPS 網站或 localhost 開啟本遊戲。直接開 file:// 檔案可玩本機，但不能完成 Google 登入。iPad 請用 Safari 網站頁面並允許登入彈出視窗。
  6. 若要讓其他裝置免貼設定，可把同一物件填入原始碼的 FIREBASE_CONFIG。
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /saves/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
